# C++ 算法实验室

这是可运行的 C++ 算法交互式学习网站。

## 当前算法

- 冒泡排序
- 选择排序
- 插入排序
- 二分查找

## 已实现

### 讲解与动画

- 每个算法的核心讲解、循环不变量和复杂度说明
- 数组动画：上一步、下一步、播放、暂停、重置、速度调节
- 自定义数组和逆序、接近有序、随机数组预设
- 二分查找支持自定义目标值，并展示搜索区间和中点
- 比较、交换、移动、检查次数和区间大小等动态指标
- C++17 代码与动画步骤行级同步

### 选择题

- 每个算法 4 道选择题，共 16 道
- 按算法统计答题次数、总正确率和首次正确率
- 每题历史答题数据和错后重答

### 编程题

- 每个算法 3 道编程题，共 12 道（升序 / 统计量 / 变式）
- 每道题包含题目描述、输入输出格式、若干组测试用例和可选提示
- 在本地编辑器里写好代码后粘贴到输入框，点「提交判断」即可
- 由内置的 JSCPP 解释器**在浏览器本地运行**，不联网、不上传代码
- 代码运行在 Web Worker 中，超过 4 秒自动终止，避免死循环卡死页面
- 逐条对照测试用例，未通过时展示「你的输出」与「期望输出」的差异
- 语法错误、超时、结果不符都有对应的中文提示
- 每道题的代码本地自动保存，刷新不丢失
- 全部通过后自动记入学习日志并打上通过标记

### 通用

- 自动学习日志和手动笔记
- 使用 `localStorage` 在浏览器本地保存数据

## 运行

可以直接双击 `index.html`（推荐，开箱即用，无需联网），也可以在当前目录运行：

```powershell
python -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173/
```

## 关于编程题的判题

- 执行引擎是 [JSCPP](https://github.com/felixhao28/JSCPP)（MIT License），一个用 JavaScript 写的 C++ 解释器。
- 完整源码内联在 `index.html` 的 `<script id="jscppSource">` 文本块中，原始文件保留在 `vendor/JSCPP.js`，因此**离线可用**。
- 它支持 C++ 的一个子集：基本语法、数组、循环、函数、`cin` / `cout` 和常用运算符，足以覆盖本站的课堂练习；不支持模板、多线程和完整 STL。
- 输出比对会忽略行尾空白、空行和多余空格，`1  2 4` 与 `1 2 4` 视为相同。
- 若需要完整的 C++17（含 STL、模板），需要改用在线判题服务或本地安装编译器，本页面不包含该能力。
